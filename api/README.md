# REST API

API w FastAPI, które udostępnia dane z bazy PostgreSQL (host z zmiennej `DB_HOST`).

Endpointy: patrz tabela w README w głównym folderze. Dokumentacja Swagger będzie pod `http://localhost:8000/docs`.

Do zrobienia: `main.py`, `requirements.txt`, `Dockerfile` oraz odkomentowanie usługi `api` w `docker-compose.yml`.
